`verified` means the row's proof command is currently green.

- `\input{sub.tex}\foo`
- `\input{sub.tex}\meaning\foo`
- `\input{sub.tex}\edef\foo{\bar}\def\bar{A}\foo`

- `\input{sub.tex}\string\foo`
- `\input{sub.tex}\expandafter\bar\foo`
